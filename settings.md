# Settings Panel  
## Full Configuration of Detection & Application Behavior

The **Settings Panel** allows users to configure engines, thresholds, directories, themes, languages, and quarantine behavior.

Introduced in v2.0.0 and expanded in **[v2.0.3](ca://s?q=Open_v2.0.3_release_notes)**.

---

## 🧩 Sections

### **1. Detection Settings**
- Engine selection (int8, fp16, full, ifnude)  
- Threshold configuration  
- GPU/CPU fallback toggle  
- Video frame sampling (v2.0.1+)  

### **2. Directory Settings**
- Scan directories  
- Exclusion list  
- Default quarantine directory  
- Default move-to directory  

### **3. Appearance**
- Light/dark theme  
- Localized avatars  
- UI language (EN/FR/ES)  

### **4. Quarantine**
- Organize by category  
- Preserve folder structure  
- Log file creation  
- Double-click action  

### **5. Licence**
- Key entry  
- Validation  
- Status display  
- Error messages  

---

# ⚙️ Behavior

Settings are stored in:
%APPDATA%/NsfwManager/config.json


Changes apply instantly and persist across sessions.
