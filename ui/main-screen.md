# Main Screen  
## Central Hub for Scanning & Reviewing Files

The **Main Screen** is the core interface of NSFW Manager.  
It displays scan results, previews, actions, and navigation elements.

Introduced in v1.0.0 and significantly improved in **[v2.0.0](ca://s?q=Open_v2.0.0_release_notes)** and **[v2.0.3](ca://s?q=Open_v2.0.3_release_notes)**.

---

## 🧩 Layout Overview

The main screen includes:

### **1. Result List**
- Displays detected files  
- Shows engine score  
- Indicates file type (image/video)  
- Supports right-click actions  
- Integrates with SQLite cache  

### **2. Preview Panel**
- Async image preview  
- Video preview (v2.0.1+)  
- Metadata display  
- Quick actions  

### **3. Action Bar**
- Scan  
- Clear results  
- Settings  
- Quarantine  
- Licence panel  

### **4. Status Bar**
- Scan duration  
- Engine used  
- Cache status  
- File count  

---

# 🖱 Right‑Click Menu

Introduced in v2.0.3:

- Properties  
- Delete  
- Move

# ⌨️ Keyboard Shortcuts

| Action | Shortcut |
|-------|----------|
| Properties | Ctrl+P |
| Send to Directory | Ctrl+T |
| Clear results | Del |
| Refresh | F5 |

---

# 🧪 Cache Integration

The main screen uses the SQLite cache to:
- Display cached results instantly  
- Skip re-scanning known files  
- Show cached thumbnails
