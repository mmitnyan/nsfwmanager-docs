# NSFW Manager v1.0.0  
## First Public Release — January 2026

NSFW Manager 1.0.0 is the first public version of the application.  
It represents the transition from early prototypes to a usable NSFW detection tool with folder scanning, quarantine, and deletion capabilities.  
This release was shared with a small community to validate the core functionality before the major v2 refactor.

---

## 😂 Origin Story (Fun Note)

The very first version of NSFW Manager was born after a rather embarrassing moment at home.  
During a casual evening, an unexpected “surprise” image appeared while browsing old folders — the kind of moment where you wish your computer had warned you first.

After searching for existing tools, only two products seemed to exist: **Snitch** and **Media Detective**.  
Both looked like they came straight out of Windows 95, and worse: **they completely failed to detect the content** that caused the incident.

So Manuel did what any determined developer would do:

> “Puisque aucun logiciel ne fait le travail correctement… je vais le créer moi‑même.”

And thus, **NSFW Manager v1.0.0** was born — a personal solution that eventually grew into a full product.

# 🚀 Core Features

## **Folder Scanning**
- Recursive directory scanning  
- Detection of NSFW content using early ONNX models  
- Basic threshold logic  
- First integration of the external **ifnude** engine  
- Initial performance tuning

## **Quarantine System**
- Move detected files to a safe quarantine folder  
- Restore files back to their original location  
- Prevent accidental deletion  
- Early UI for quarantine management

## **Deletion Options**
- Send files to Windows Recycle Bin  
- Permanent delete option  
- Error handling for locked or inaccessible files

## **Basic UI & Workflow**
- Simple list-based interface  
- Preview panel for images  
- Basic configuration options  
- Early README included in the project

# 📁 Technical Notes

### **Architecture**
- Pre-MVC architecture  
- Logic and UI tightly coupled  
- No modular engine system yet  
- No configuration tabs  
- No licence system  
- No video support

### **Packaging**
- No MSI installer  


### **Engines**
- Early ONNX model integration  
- First appearance of **ifnude**  
- No GPU acceleration  
- No multi-engine selection
