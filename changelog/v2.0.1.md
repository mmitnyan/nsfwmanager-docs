# NSFW Manager v2.0.1  
## Video Expansion Release — June 2026

NSFW Manager 2.0.1 is the first major multimedia extension of the product.  
This version introduces full video detection, preview, GPU acceleration, and a refined MSI packaging pipeline.  
It marks the transition from a photo-only tool to a complete NSFW scanner for both images and videos.

---

## 📌 Overview

- **Tag:** `2.0.1`  
- **Development window:** 2026‑06‑13 → 2026‑06‑15  
- **Release date:** 2026‑06‑15  
- **Milestone type:** Major feature expansion  
- **Focus:** Video detection, preview, GPU acceleration, MSI stability

This release is built on top of the v2.0 architecture refactor and extends the detection pipeline to support video formats and frame extraction.

---

## 🚀 Major New Features

## **Video Detection Engine**
- Full video scanning pipeline  
- Frame extraction and sampling  
- Integration with existing ONNX engines  
- Support for common formats: mp4, mov, mkv, avi, webm  
- Automatic fallback when frames cannot be decoded

## **Video Preview Panel**
- Embedded video player  
- Thumbnail extraction  
- Seek bar and frame navigation  
- Unified UI with the existing image preview panel

## **GPU Acceleration (d3d11va)**
- Hardware-accelerated decoding via **d3d11va**  
- Automatic fallback to CPU when GPU is unavailable  
- Improved performance on large or high‑resolution videos

## **New Video Settings Tab**
- Frame sampling configuration  
- Maximum video size limit  
- Format filters  
- GPU/CPU toggles  
- Error reporting and diagnostics

---

## 🔧 Improvements

## **MSI Packaging & Build Pipeline**
- Stabilized MSI generation  
- Improved reliability of installation/uninstallation  
- Better handling of video-related dependencies  
- Expanded test coverage for Windows 10/11

## **UI Integration**
- Video results appear in the same list as photos  
- Unified action buttons (delete, move, quarantine)  
- Consistent preview behavior across media types

---

## 🐞 Fixes

- Thumbnail extraction issues resolved  
- Preview crashes fixed  
- Incorrect “ignored” state for certain video formats corrected  
- Configuration panel bugs addressed  
- Improved error messages for unsupported codecs

## 📁 Technical Notes

### **Detection Pipeline Changes**
- New video backend integrated into the main scanning loop  
- Frame sampling logic added to engine inference  
- GPU/CPU fallback logic implemented  
- Video metadata extraction added to Properties panel

### **Performance Notes**
- GPU decoding significantly reduces scan time  
- CPU fallback remains stable and predictable  
- Video preview is asynchronous to avoid UI freezes
