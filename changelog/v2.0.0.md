# NSFW Manager v2.0.0  
## Architecture Refactor Release — June 2026

NSFW Manager 2.0.0 is the foundational release that transformed the project from a simple NSFW scanner into a fully structured, configurable, multi‑engine desktop application.  
This version introduces a complete MVC refactor, a new configuration system, multi‑engine support, internationalization, theming, and the first licence system.

It is the release that establishes NSFW Manager as a real product rather than a prototype.

---

## 📌 Overview

- **Tag:** `2.0.0`  
- **Development window:** 2026‑05‑24 → 2026‑06‑01  
- **Release date:** 2026‑06‑01  
- **Milestone type:** Major architectural refactor  
- **Focus:** MVC architecture, configuration system, multi‑engine support, licence system, packaging

This release marks the beginning of the “v2 generation” of NSFW Manager.

---

## 🧱 Major Architectural Changes

## **Complete MVC Refactor**
- Full rewrite of the application structure  
- Separation of UI, logic, and engine layers  
- More maintainable codebase  
- Foundation for future modules (video, cache, diagnostics)

## **New Configuration System**
- Centralized settings panel  
- Adjustable detection threshold  
- Engine selection (int8, fp16, full, ifnude)  
- Directory management  
- Theme selection (light/dark)  
- Language selection (EN/FR)

## **Quarantine & File Operations**
- Unified file movement logic  
- Quarantine folder with restore workflow  
- Improved delete and permanent delete actions  
- More reliable error handling

---

## 🌍 Internationalization & UI Enhancements

## **Multilingual UI**
- English and French fully supported  
- Early groundwork for Spanish (completed in v2.0.3)

## **Light/Dark Themes**
- Full theme engine  
- Custom dialogs and consistent styling  
- Better accessibility and readability

## **Improved UX**
- First‑launch guided defaults  
- Clearer menus and dedicated configuration tabs  
- Better error messages and fallback logic

---

## 🔐 Licence System (Introduced May 27, 2026)

The licence system was added during this cycle:

- Trial mode  
- Free mode  
- Paid licence key  
- Feature gating based on licence  
- Secure validation workflow  
- Early anti‑tampering logic

This is the foundation of the hardened licence system completed in v2.0.3.

---

## ⚙️ Multi‑Engine Support

NSFW Manager v2.0.0 introduces support for multiple detection engines:

- **int8** — fastest  
- **fp16** — balanced, GPU‑only  
- **full** — maximum accuracy  
- **ifnude** — external engine with granular nudity classification

This release also introduces:

- Engine selection UI  
- Engine fallback logic (GPU → CPU)  
- ONNX runtime integration  
- First version of the engine diagnostics panel

---

## 📦 Packaging & Deployment

## **New Windows Packaging**
- First modern MSI packaging  
- Product renaming and legal validation  
- Logs and configuration moved to:  
  `%APPDATA%/NsfwManager/`  
- Cleaner installation structure  
- Better compatibility with Windows 10/11

This packaging work is the basis for the silent per‑user MSI introduced in v2.0.3.
