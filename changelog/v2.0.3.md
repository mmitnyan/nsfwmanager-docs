# NSFW Manager v2.0.3  
## Performance Upgrade & UX Expansion — July 2026

NSFW Manager 2.0.3 is the second official public release of the v2 generation.  
This version delivers a major performance boost through the new SQLite scan cache, a significantly improved user experience, hardened licence security, and a fully silent per‑user MSI installer.

It is the most polished and performant version of NSFW Manager to date.

---

## 📌 Overview

- **Tag:** `2.0.3`  
- **Development window:** 2026‑07‑08 → 2026‑07‑23  
- **Release date:** July 2026  
- **Milestone type:** Performance upgrade & UX improvements  
- **Focus:** Instant caching, enriched interface, licence hardening, silent MSI

This release builds directly on the public release v2.0.2 and completes the caching system introduced in that version.

---

# 🚀 Major New Features

## **Instant SQLite Scan Cache**
- Full activation of the caching system introduced in v2.0.2  
- Instant re-scan for previously analyzed files  
- Video thumbnails included  
- Engine-aware and threshold-aware caching  
- MD5 optional verification  
- Dramatically faster repeated scans

## **Right‑Click Context Menu**
Available on both result lists:
- Delete  
- Move  
- Properties  
- Quarantine  
- Open file location  

## **Properties Panel (Ctrl+P)**
- Detailed file information  
- Dimensions, metadata, timestamps  
- Video preview  
- Engine results per model  
- Keyboard shortcut support

## **Configurable Double‑Click Action**
Users can choose what double‑click does:
- Open Properties  
- Move to Directory  
- Move to Folder  
- Quarantine  

## **New Shortcut: Ctrl+T**
- “Send to Directory”  
- Faster workflow for bulk organization

## **Localized Avatars & Portraits**
- English  
- French  
- Spanish  
- Assets optimized (16 MB → 2.4 MB)

## **Scan Duration Display**
- Total scan time shown after each scan  
- Useful for performance comparison and diagnostics

## **New “Clear Results” Button**
- Replaces “Cancel” after scan  
- Allows instant reset of the results list

---

# 🔐 Licence Security Hardening

The licence system introduced in v2.0.0 is significantly reinforced:

- Machine binding  
- HMAC‑SHA256 verification  
- Anti‑rollback protection  
- Verified SSL communication  
- More robust trial/free/paid gating  
- Better error messages and validation flow

This makes licence handling more secure and reliable for commercial distribution.

---

# 🔧 MSI Installer Improvements

## **Silent Per‑User MSI**
- No UAC prompt  
- No admin rights required  
- Fully silent installation  
- Fixes Windows Installer errors:
  - **1925**  
  - **1303**  
- MSI package reduced by ~170 MB  
- Cleaner installation footprint

This installer model is ideal for non‑technical users and enterprise environments.

---
