# NSFW Manager — Documentation

NSFW Manager is a Windows desktop application that helps you scan, review, and manage files flagged as potentially inappropriate content. It provides a fast, privacy-respecting local workflow — no files are ever uploaded to external servers.

## Features

- **Content scanning** — detect and flag NSFW images and videos on your local drives.
- **Scan cache** — avoid rescanning unchanged files thanks to a persistent result cache.
- **Video support** — frame-based analysis for common video formats.
- **Quarantine** — safely isolate flagged files without permanently deleting them.
- **Properties panel** — inspect file metadata and scan results in one place.
- **Keyboard shortcuts** — navigate and act on results without leaving the keyboard.
- **Per-user MSI installer** — install without administrator rights via the Microsoft Store or a standalone MSI.
