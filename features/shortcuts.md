# Keyboard Shortcuts
## Faster Workflow and Power-User Commands

NSFW Manager includes keyboard shortcuts that accelerate navigation, file management, and review. They are especially useful when processing large scan results without touching the mouse.

---

## Global Shortcuts

These shortcuts work from anywhere in the application.

| Action | Shortcut |
|---|---|
| Open Properties Panel | Ctrl+P |
| Send to Directory | Ctrl+T |
| Refresh / Reload | F5 |
| Close Properties Panel | Esc |

---

## Main Screen Shortcuts

These shortcuts apply when the main results list is focused.

| Action | Shortcut |
|---|---|
| Select next file | Down arrow |
| Select previous file | Up arrow |
| Open file location | Ctrl+L |
| Quarantine file | Q |
| Delete file (to Recycle Bin or permanent, per your setting) | Delete |
| Permanent delete | Shift+Delete |
| Clear results list | Del (when no file is selected) |

**Note on the Delete key:** The `Delete` key is context-sensitive. When one or more files are selected in the results list, it triggers the configured delete action for those files. When nothing is selected, it clears the entire results list (with a confirmation prompt). These are two distinct actions sharing the same key.

Related: [Delete](./delete.md) — [Main Screen](../ui/main-screen.md)
