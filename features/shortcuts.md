# Keyboard Shortcuts  
## Faster Workflow & Power‑User Commands

NSFW Manager includes a set of keyboard shortcuts designed to accelerate navigation, file management, and review.  
These shortcuts are available on the **Main Screen**, **Properties Panel**, and **Quarantine Manager**.

Shortcuts were introduced progressively across versions, with major additions in **[v2.0.3](ca://s?q=Open_v2.0.3_release_notes)**.

---

## 🎯 Purpose

Shortcuts allow users to:
- Navigate faster  
- Perform actions without menus  
- Speed up bulk operations  
- Improve productivity during large scans  

They are especially useful when reviewing hundreds or thousands of files.

---

# ⌨️ Shortcut List

## **Global Shortcuts**

| Action | Shortcut |
|-------|----------|
| Open Properties Panel | **Ctrl+P** |
| Send to Directory | **Ctrl+T** |
| Clear Results | **Del** |
| Refresh Preview / Reload | **F5** |
| Close Properties Panel | **Esc** |

---

## **Main Screen Shortcuts**

| Action | Shortcut |
|-------|----------|
| Select next file | ↓ |
| Select previous file | ↑ |
| Open file location | Ctrl+L |
| Quarantine file | Q |
| Delete file | Delete |
| Permanent delete | Shift+Delete |
